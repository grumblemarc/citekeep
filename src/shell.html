How to use Citekeep

Citekeep keeps your references, checks the citations you typed, and works with your PDFs. Each part below takes a minute to read.

1. Build your library

  1. Open a document tab: choose a Word file with a reference list. Every reference goes into your library.
  2. Or add one at a time: Look up a DOI or ISBN in the Library, New to type it in, or Add from PDF.
  3. Organize with tags. Use a slash for folders, like Dissertation/Chapter 2. Tag shown tags everything currently listed.
  4. Duplicates finds the same work entered twice and merges it.

2. Check a chapter

  1. Open the chapter on the Open a document tab. Citekeep lists citations with no reference, references never cited, near-miss spellings, and APA 7 problems.
  2. Pick the corrections you want, then Save a linked copy. Every citation in the copy is linked to its reference (Ctrl+click in Word). Your original isn't changed.
  3. Tick Rebuild the reference list to replace the list with a fresh, alphabetized one holding only what the text cites.
  4. Choose several chapters at once to check them against one combined list.

3. Link your PDFs

  1. In Settings → Your PDFs, choose the folder that holds your PDFs, then click Match files to references. File names don't matter; Citekeep reads the DOI and title inside each PDF.
  2. For a reference without a PDF: Free PDF finds a legal free copy, Search for PDF searches the web, and anything you download is filed and linked automatically.
  3. Tick Search inside PDFs in the Library to find words in your articles.

4. Set up AI (optional)

  1. In Settings → AI drafting, choose LM Studio (free, on your computer) or the Claude API (your own key).
  2. For LM Studio: start its server, turn on Enable CORS, load your model with a context length of 32768, then click Test connection.
  3. AI is used for two things: drafting matrix rows and checking claims.

5. Build the matrix

  1. Matrix tab: Import a matrix brings in an existing Word matrix, row by row.
  2. Fill or edit a row in the Library under each reference's Matrix row, or use Draft with AI. Drafts stay marked until you accept them.
  3. Save matrix (.docx) writes the table and its APA reference list.

6. Check claims

  1. Open a chapter, then click Check claims. For each cited sentence, the AI reads the cited PDF and says whether it supports the sentence, quoting the passage and page.
  2. Work through Show only claims that need attention. PDF page opens the PDF at the passage; Recheck asks again.
  3. Results are saved, so you can stop and come back. Save report (.docx) gives you a copy to keep.

7. Reference lists and export

  1. Reference list tab: build an APA list from your library or one document, adjust the order by dragging, then copy it or save it as Word.
  2. Import & export: paste a reference list, or move references to and from Zotero with RIS or BibTeX.

8. Your data, backups and updates

  1. Everything lives in Documents\Citekeep. A backup is made each day; the last 10 are kept (Settings → Your Citekeep data).
  2. New computer: Export transfer file here, Import transfer file there.
  3. Updates: Citekeep checks once a day, or click Check for updates. It never installs an older version over a newer one.

Import & export
